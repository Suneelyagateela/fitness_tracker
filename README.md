# Fitness Tracker 🏋️‍♂️

A Java-based application that tracks fitness workouts using a MySQL database backend.

## Features
- **CRUD Operations:** Add, view, update, and delete workout logs.
- **Analytics:** Calculates total volume lifted and personal bests directly via SQL.
- **Persistence:** Uses JDBC and MySQL to save data securely.

## Setup Instructions
1. Ensure you have MySQL installed.
2. Create a database named `fitness_tracker`.
3. Update the database credentials in `WorkoutManager.java`.
4. Run `Main.java` to start the application.# fitness_tracker
